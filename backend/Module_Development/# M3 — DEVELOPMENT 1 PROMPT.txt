# 5. COURSE LIFECYCLE

Implement the Course lifecycle as a controlled state machine.

Conceptually:

```text
DRAFT
  │
  │ submit
  ▼
PENDING_APPROVAL
  │
  ├── reject ──────► REJECTED
  │
  └── approve ────► approved lifecycle state
                           │
                           │ publish
                           ▼
                       PUBLISHED
                           │
                           │ archive
                           ▼
                       ARCHIVED
```

The exact mapping must use the **existing Prisma enum and application conventions**.

Never perform arbitrary status mutation from a generic update endpoint.

For example, clients must not be allowed to send:

```text
{
  "status": "PUBLISHED"
}
```

to bypass the publication workflow.

Lifecycle transitions must be explicit service operations.
