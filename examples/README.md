# Integration Examples

Use this directory to store demo modules, sandbox code, or alternative configurations.
For example:
- `examples/mongodb-prisma/`: A reference Prisma schema and setup configured to use MongoDB instead of PostgreSQL.
- `examples/oauth-passport/`: Reference middleware implementing OAuth2 Google/GitHub logins via Passport.js.
